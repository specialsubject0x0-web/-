🔗 即時資料來源（給 Power BI 重新整理用）

這 4 個網址每次被讀取都會回傳 BizForm 最新資料（CSV，UTF-8）。在 Power BI 用「Web」資料來源連到它們，就不用再手動匯出 Excel。

設定步驟
  1. Power BI Desktop → 取得資料 → Web → 貼上上面的網址（驗證選「匿名」）→ 載入。4 張表各連一次。
  2. 把報表的資料表來源換成這些查詢（欄位名稱與匯出的 Excel 相同），重新發布。
  3. Power BI 服務 → 資料集 → 設定 → 排程重新整理，開啟並選頻率；資料來源憑證選「匿名」。
  4. 「發佈到網路」的內嵌畫面，資料更新後最多約 1 小時才會反映。
  5. 若網站設了存取碼，網址後面加 ?key=存取碼。
